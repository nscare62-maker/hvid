⚠️ How to Start the Backend

  1. Open a new terminal (Command Prompt or PowerShell)
  2. Navigate to backend folder:
    cd backend
  3. Install dependencies (first time only):
    npm install
  4. Start the server:
    npm run start:dev
  5. Wait for message: HVID Backend → http://localhost:3000/api
  6. Refresh this page to check status
